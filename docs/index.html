GLOSSARY

Terms

Machine learning
Software that learns a pattern from examples instead of following hand-written rules.
Model
A formula with adjustable settings that turns features into a prediction.
Feature
A number describing a molecule, such as logP or MW.
Target
What we predict: log10 HLM clearance.
Training / unseen compounds
The model studies training compounds. Unseen compounds are held back to test it.
Scaffold split
Unseen compounds come from different chemical series than training compounds.
Overfitting
Memorising training data, noise included, so new compounds are predicted worse.
R²
Share of variation explained on unseen compounds. 1 is perfect, 0 is no better than the average.
Spearman
How well the model ranks compounds, ignoring exact values.
RMSE
Typical error in log10 units.
Descriptors
logP: lipophilicity. TPSA: polar surface area. MW: weight. HBD / HBA: H-bond donors / acceptors. RotB: rotatable bonds. Fsp3: share of sp3 carbons. AromRings: aromatic rings.
HLM clearance
How fast human liver microsomes remove a compound. Higher = shorter half-life.
logD_pred
Predicted logD from a model trained on AstraZeneca data.
Stacking
Feeding one model's prediction into another model as a feature.

MODEL FAMILY 1

Tree models

A tree splits compounds with yes/no questions on features. Forests average many trees. Boosting adds small trees that correct earlier ones.

Key terms

Decision tree
Yes/no questions on features. A compound lands in a leaf and gets that leaf's average.
Split
One question, such as logP ≤ 2.9.
Depth
Questions in a row.
Leaf
A bottom box. Its prediction is the training average of the compounds in it.
Random forest
Many deep trees on random resamples of the data; predictions are averaged.
Ensemble
Several models combined.
Gradient boosting
Small trees added in sequence, each fitting the error left by the earlier ones.
Learning rate
Share of each new tree's correction that is applied.

MODEL FAMILY 2

Neural networks

Each line is a weight: red raises the next neuron, grey lowers it, thicker is stronger.

Key terms

Neuron
Inputs × weights, plus a bias, passed through an activation.
Weight
Strength of a connection. Training changes the weights.
Bias
A learned offset added in each neuron.
Layer
A column of neurons: input, hidden or output.
ReLU
Negative values become 0; positive values pass unchanged.
Parameters
All weights and biases.
Epoch
One pass through the training data.
Loss
Average squared error. Training lowers it.
Learning rate
Size of each weight update.
Dropout
Randomly switching off neurons during training to curb overfitting.
Validation set
Training compounds held aside to watch for overfitting.
Best epoch
The epoch with the lowest validation loss. Keeping it is early stopping.
Standardising
Rescaling features to similar ranges.
Message passing
Chemprop: atoms exchange vectors with bonded neighbours over several rounds.

Features

Inputs the network may use. Shared across tabs.

Controls

Stages between inputs and output.
Neurons per hidden layer.
Share of neurons switched off each step.

Graph networks and Chemprop

Chemprop reads the molecular graph, not a descriptor table. Each atom passes messages to bonded neighbours; after k rounds an atom carries information from everything within k bonds. Atom vectors are then pooled and a small network predicts. It trains in Python (notebook 06), not in this page.

MODEL FAMILY 3

GPT

A GPT predicts the next token from everything before it, then repeats. Here the text is SMILES. ChatGPT works the same way at far larger scale.

Key terms

GPT
A model trained to predict the next token, then used to write text token by token.
Token
A piece of text. Here: an atom, bond, bracket or ring digit.
Vocabulary
The tokens the model knows.
Embedding
The list of numbers that represents one token.
Attention
Each token weighs earlier tokens by how relevant they are.
Transformer
A stack of attention + feed-forward blocks.
Causal mask
Stops a token looking at later tokens.
Pre-training
Learning general patterns before a specific task.
Next-token loss
How surprised the model is by the true next token.
Temperature
Low picks the likeliest token; high picks more varied ones.
SMILES
Text for a molecule, such as CC(=O)N.
